# Contributing.

Hello. Thanks for being interested in contributing
:D.

## Can I contribute?

Of course! Anyone can, if they follow the following rules.

## Can I use AI? [LLM POLICY]

As much as we understand that it may be harder
without AI to contribute.
...We don't really like AI contributions as they make the project messy. 

If you do tho please follow the rules. 

- Less than 30% of your code can be Ai.
- You must completely understand what it wrote.
- You must rewrite all comments the LLM wrote.
- You must not write your PR completely with AI.

If you break any of these rules your PR will be rejected and you might be blocked.
