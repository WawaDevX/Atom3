## Running Atom3 Programs

Atom3 programs use the `.atom` file extension.

To execute a program, run the Atom3 executable with the `run` command, followed by the path to your script:

```bash
./atom3 run hello.atom
```

Replace `atom3` with the name of your downloaded executable and `hello.atom` with the name or path of your Atom3 script.

### Examples

```bash
./atom3 run examples/hello.atom
./atom3 run my_program.atom
```
