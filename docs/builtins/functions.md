# Builtin functions

Builtin functions are default functions of ATOM that cant be 

| function | description | returns |
|------|----------|--------|
| Arrlen(ARRAY) | Returns the amount of items in an array | the amount of items in an array |
| print(string/integer/expression) | Prints to the console | - |
| wait(integer) | Waits a certain amount of seconds | - |
| input(string) | Prints the question thats put in the brackets and then waits for user input | the user input |
| exit() | exits the program | - |
