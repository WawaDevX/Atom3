# Variables

Variables are named "boxes" you can put data into.

## Creating variables

To create variables in atom:
```
var (Variable name) = (Function/integer/string/expression/array)
```

for example:

```
var name = "jessica"
```
for a string (text)

```
var result = [5+5]
```

for a expression (math)

```
var people = {"bob", "james", "erica"}
```

for arrays (lists)

or even

```
var name = getname()
```
to use a function. 

<sub> as a note: Functions either have to be defined or be a language builtin. </sub>

## Using Variables

Variables can be used in various ways for example you can use it in a print function to print somebodys name

```
var name = "erica" // define the variable

print(name) // print it out using the print() builtin
```

other ways are documented in other files
