# Creating variables

To create variables in atom:
```
var (Variable name) = (Function/integer/string/expression)
```

for example:

```
var name = "jessica"
```
for a string (text)

```
var result = [5+5]
```

for a expression (math)

or even

```
var name = getname()
```
to use a function. 

<sub> as a note: Functions either have to be defined or be a language builtin. </sub>
