# Functions

a function is a reusable block of code designed to perform a specific task.

# Creating a function

```
func functionname(arg1, arg2...) {
  // do something here
}
```


### Examples:
```
func sayhello() {
  print("hello")
}
```

and when called like 

```
sayhello()
```

<sub> output: hello </sub>
