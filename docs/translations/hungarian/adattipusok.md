**### Ez nincs befejezve**

A függvény argumentumaiban, visszatérési értékeiben és változóiban tetszőleges értékeket használhatsz.

Például:

```
// Egy betusor
print("hello")

// Matek
print([5 + 5])

// Egy egész szám
print(5)

var nev = "john" // Egy betusor
var eletkor = 20 // Egy egész szam
var magassag = [20 + 5] // matek
var gyerekek = {"john jr", "dave"} // egy lista
var eletben_van = true // Egy boolean

print(john) // Egy változó
print(true) // Egy boolean
```

a print az csak egy példa. ez minden függvény bemenetben így működik.
