# Függvények
<sub>ez egy borzalmas magyar szó de müködik szóval ez van.</sub>

A függvény egy újrafelhasználható kódrészlet, amit egy adott feladat csinálására terveztek.

# Hogyan csínálsz függvényeket?

```
func fuggvenynev(bemeno1, bemeno2...) {
  // csinalj itt valamit
}
```


### Példák:
```
func mondszia() {
  print("szia")
}
```

és a függvény hívásához:

```
sayhello()
```
