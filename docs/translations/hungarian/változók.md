# Változók
<sub>ez egy borzalmas magyar szó de müködik szóval ez van.</sub>

A változók mondhatnád cimkézett dobozok amikbe más más adatokat tárolnak.

## Változók létrehozása

```
var (Változónév) = (Függvény/egészszám/betűsor/változó/lista)
```

for example:

Egy betűsor (szöveg) esetén:

```
var nev = "david"
```
Egy matematikai művelet esetén:

```
var eredmény = [5+5]
```
a listákhoz:

```
var emberek = {"bob", "james", "erica"}
```


vagy esetleg egy függvényhez:

```
var name = getname()
```

<sub> Megjegyzés: A függvényeket vagy definiálni kell lenniük vagy a programozási nyelv beépített függvényeinek kell lenniük. </sub>

## Változók használata

A változókat többféleképpen is fel lehet használni. Például egy print függvényben kiírhatod valakinek a nevét.

```
var nev = "erika" // a nev valtozo aminek a erteke "erika" 

print( nev) // ki "print"elni a "nev" valtozó értékét
```

A többi felhasználási módot más fájlok dokumentálják.
