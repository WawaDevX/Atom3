# Beépített függvények

A beépített függvények az ATOM alapértelmezett függvényei, amelyeket nem kell külön definiálni.

| Függvény | Leírás | Return |
|------|----------|--------|
| Arrlen(lista neve) | Visszaadja a lista elemeinek számát | A lista elemeinek száma |
| print(valami) | Kiírja az értéket a konzolra | - |
| wait(másodperc) | Meghatározott számú másodpercig várakozik | - |
| input(kérdés) | Kiírja a zárójelek között megadott kérdést, majd felhasználói bevitelre vár | A felhasználó által megadott érték |
| exit() | Kilép a programból | - |
