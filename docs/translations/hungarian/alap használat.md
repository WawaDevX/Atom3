## Atom3 programmok futattása

Atom3 programmok a `.atom` befejezést használják.

Ahhoz hogy futassunk egy programmot, futatnunk kell a `run` parancsot, amit a `atom3` parancssorból hívjuk meg.

```bash
./atom3 run hello.atom
```

Az `atom3` részt cseréld ki a te letöltött fájlnevedre (Pl.: `atom3-windows-amd64.exe`) és
a `hello.atom` részt a te `.atom` szkript fájlod nevével.

### Példák

```bash
./atom3 run examples/hello.atom
./atom3 run my_program.atom
```
